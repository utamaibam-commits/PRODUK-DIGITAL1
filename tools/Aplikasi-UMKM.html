Pilih HP Anda

Buka link aplikasi KasRapi dari email/halaman pembelian Lynk.id, lalu pasang ikonnya di layar HP. Tidak perlu aplikasi tambahan, gratis. Setelah dibuka sekali, KasRapi jalan tanpa internet.

Pasang di Android (Chrome)

  1. Buka link KasRapi di Chrome

    Ketuk link aplikasi dari Lynk.id. Jika terbuka di browser lain (WhatsApp/Instagram), ketuk menu ⋮ → Buka di Chrome.

  2. Ketuk menu ⋮ di pojok kanan atas

    Pilih Instal aplikasi atau Tambahkan ke Layar utama.

  3. Ketuk Instal / Tambahkan

    Ikon KasRapi muncul di layar HP seperti aplikasi biasa.

  4. Selalu buka dari ikon

    Ketuk "Isi Data Contoh" untuk mencoba. Data tersimpan di HP Anda dan jalan tanpa kuota.

Pasang di iPhone (Safari)

  1. Buka link KasRapi di Safari

    Harus Safari (kompas biru). Jika terbuka di WhatsApp/Instagram, ketuk ikon kompas atau ⋯ → Buka di Safari.

  2. Ketuk tombol Bagikan

    Ikon kotak dengan panah ke atas, di bawah layar (iPad: di atas).

  3. Pilih "Tambah ke Layar Utama"

    Geser daftar ke bawah, ketuk Tambah ke Layar Utama → Tambah.

  4. Mulai catat dari ikon KasRapi

    Buka dari ikon di layar utama, bukan dari Safari. Di iPhone, data di ikon dan di Safari terpisah.

Selalu buka lewat ikon yang sama. Jangan hapus "data situs/riwayat" browser, dan lakukan Backup tiap minggu dari menu Pengaturan.

Cara Pakai 1 Menit

  1. Atur kanal & produk

    Pengaturan → isi potongan Shopee/TikTok Shop sesuai tagihan toko. Lalu tambah produk di menu Stok (harga jual, modal, stok).

  2. Catat setiap transaksi

    Tekan tombol +. Pilih Penjualan / Pengeluaran / Beli Stok / Uang Pribadi. Laba bersih terhitung otomatis.

  3. Cek Beranda & Laporan

    Lihat laba bersih, kanal paling untung, stok menipis, dan kasbon. Kirim ringkasan ke WhatsApp atau simpan PDF.

Pertanyaan Umum

Apakah butuh internet?

Hanya sekali, saat pertama membuka link dan memasang ikon. Setelah itu semua berjalan di perangkat Anda tanpa kuota. Internet hanya dipakai lagi jika Anda menekan tombol kirim ke WhatsApp.

Datanya disimpan di mana? Aman?

Di penyimpanan browser perangkat ini (localStorage). Link hanya dipakai untuk memasang aplikasi; data transaksi Anda tidak pernah dikirim ke server mana pun. Jangan hapus "data situs/riwayat" browser, dan lakukan Backup rutin.

Ganti HP, datanya bagaimana?

Pengaturan → Backup Data (file .json). Kirim file itu ke HP baru, buka KasRapi di HP baru → Restore Data.

Apa bedanya "Pengeluaran", "Beli Stok", dan "Uang Pribadi"?

Pengeluaran = biaya usaha (gas, ongkir, listrik, iklan) yang mengurangi laba. Beli Stok = belanja barang dagangan; menambah stok dan mengurangi kas, tapi laba baru dihitung saat barang terjual (lewat modal/HPP). Uang Pribadi = uang usaha yang Anda pakai untuk keperluan rumah; mengurangi kas, tidak mengurangi laba usaha.

Kasbon itu apa?

Penjualan yang belum dibayar pelanggan. Laba sudah dihitung, tapi uangnya belum masuk kas. Tandai lunas di menu Laporan saat pelanggan membayar.
