Cara Memasang KasRapi di Android, iPhone & Laptop

Terima kasih sudah membeli KasRapi — Buku Kas, Stok & Laba UMKM. KasRapi dibuka lewat link, lalu ikonnya dipasang di layar HP seperti aplikasi biasa. Tidak perlu aplikasi tambahan, tidak perlu akun, dan gratis. Internet hanya dibutuhkan sekali saat pertama membuka link. Setelah itu KasRapi jalan tanpa kuota, dan semua data tersimpan di HP/laptop Anda sendiri.

Link aplikasi KasRapi: https://utamaibam-commits.github.io/PRODUK-DIGITAL1/kasrapi/

Baca bagian yang sesuai dengan HP Anda saja. Butuh waktu sekitar 1 menit.

A. Pengguna ANDROID (Samsung, Xiaomi, Oppo, Vivo, Realme, dll.)

  1. Ketuk link aplikasi KasRapi. Pastikan terbuka di Google Chrome.
  2. Jika terbuka di dalam WhatsApp/Instagram/Lynk.id, ketuk menu ⋮ → Buka di Chrome.
  3. Saat KasRapi tampil, ketuk titik tiga ⋮ di pojok kanan atas Chrome.
  4. Pilih Instal aplikasi atau Tambahkan ke Layar utama. (Kadang Chrome juga langsung menawarkan tombol Instal di bagian bawah layar.)
  5. Ketuk Instal / Tambahkan. Ikon KasRapi muncul di layar HP.
  6. Mulai sekarang buka dari ikon ini. Ketuk Isi Data Contoh untuk mencoba.

B. Pengguna iPHONE / iPAD

  1. Buka link aplikasi KasRapi di Safari (ikon kompas biru). Harus Safari, karena hanya Safari yang bisa memasang ikon ke layar utama dengan sempurna.
  2. Jika terbuka di dalam WhatsApp/Instagram/Lynk.id, ketuk ikon kompas atau ⋯ → Buka di Safari. Atau salin link lalu tempel di Safari.
  3. Ketuk tombol Bagikan (kotak dengan panah ke atas) di bagian bawah layar. Di iPad tombolnya di kanan atas.
  4. Geser daftar ke bawah → ketuk Tambah ke Layar Utama → ketuk Tambah.
  5. Ikon KasRapi muncul di layar iPhone.
  6. Mulai mencatat dari ikon itu, bukan dari Safari. Di iPhone, data yang dicatat lewat ikon dan lewat Safari tersimpan terpisah.

C. Pengguna LAPTOP / KOMPUTER (Windows / Mac)

Cara 1 (disarankan): pakai link 1. Buka link aplikasi KasRapi di Chrome atau Edge. 2. Klik ikon Instal (layar dengan panah ke bawah) di ujung kanan kolom alamat → Instal. KasRapi muncul di menu Start / Launchpad. - Safari di Mac: menu File → Tambahkan ke Dock.

Cara 2: pakai file 1. Unduh file Aplikasi-UMKM.html dari Lynk.id, pindahkan ke folder tetap (misalnya Dokumen). 2. Klik dua kali file tersebut, lalu simpan sebagai Bookmark (Ctrl+D / Cmd+D).

Data di Cara 1 dan Cara 2 tersimpan terpisah. Pilih salah satu dan gunakan terus.

D. Menjaga Data Tetap Aman

Lakukan ✅ Hindari ❌
Backup setiap minggu: Pengaturan → Backup Data. Simpan file .json ke Google Drive / WhatsApp ke nomor sendiri. Menghapus "Riwayat & data situs" / "Clear browsing data" di browser. Ini bisa menghapus catatan KasRapi.
Selalu buka KasRapi lewat ikon yang sama. Membuka di mode Penyamaran/Incognito (data tidak disimpan).
Saat ganti HP: Backup di HP lama → kirim file .json → pasang KasRapi di HP baru → Pengaturan → Restore Data. Menghapus ikon KasRapi tanpa backup dulu (di iPhone, data ikut terhapus).

E. Masalah yang Sering Terjadi

Menu "Instal aplikasi" / "Tambah ke Layar Utama" tidak ada. Pastikan link dibuka di Chrome (Android) atau Safari (iPhone), bukan di dalam WhatsApp/Instagram. Di iPhone, geser daftar menu Bagikan sampai paling bawah.

Tanpa internet, KasRapi tidak terbuka. KasRapi perlu dibuka sekali dengan internet supaya tersimpan di HP. Nyalakan data sebentar, buka ikon KasRapi, tunggu tampil, lalu matikan lagi.

Data saya hilang setelah dibuka lagi. Kemungkinan dibuka lewat jalur berbeda (misalnya Safari, bukan ikon), atau data browser terhapus. Buka lewat ikon yang biasa, lalu pulihkan dari backup terakhir (Pengaturan → Restore Data).

Tombol Kirim ke WhatsApp tidak jalan. Tombol ini butuh internet untuk membuka WhatsApp. Nyalakan data sebentar, lalu coba lagi.
