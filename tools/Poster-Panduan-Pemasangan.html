Buka link aplikasi KasRapi

Link ada di email/halaman pesanan Lynk.id, atau scan kode QR ini. Internet hanya perlu sekali saat pertama dibuka. Setelah itu KasRapi jalan tanpa kuota.

Scan dengan kamera HP
AndroidSamsung, Xiaomi, Oppo…
  1. 1Buka link KasRapi di Chrome. Jika terbuka di WhatsApp/Instagram → ⋮ → Buka di Chrome.
  2. 2Ketuk ⋮ (kanan atas) → Instal aplikasi atau Tambahkan ke Layar utama.
  3. 3Ketuk Instal. Ikon KasRapi muncul di layar HP.
  4. 4Selalu buka dari ikon ini. Jalan tanpa kuota.
Tidak ada menu "Instal aplikasi"? Pastikan link dibuka di Chrome, bukan di dalam WhatsApp/Instagram.
iPhone / iPadLewat Safari, tanpa App Store
  1. 1Buka link KasRapi di Safari (kompas biru), bukan di dalam WhatsApp/Instagram.
  2. 2Ketuk tombol Bagikan (kotak dengan panah ke atas) di bawah layar.
  3. 3Geser ke bawah → Tambah ke Layar Utama → Tambah.
  4. 4Mulai catat dari ikon KasRapi, bukan dari Safari.
Di iPhone, data di ikon dan di Safari tersimpan terpisah. Jadi selalu buka dari ikon di layar utama.
Laptop / PCWindows & Mac
  1. 1Buka link KasRapi di Chrome atau Edge.
  2. 2Klik ikon Instal di ujung kanan kolom alamat → Instal.
  3. 3KasRapi muncul di menu Start / Launchpad seperti aplikasi biasa.
  4. 4Mac dengan Safari: menu File → Tambahkan ke Dock.
Tampilan laptop otomatis memakai menu samping (sidebar) dan grafik lebih lebar.

🛡️ Agar data tidak hilang

  • ✅Backup tiap minggu: Pengaturan → Backup Data → simpan file .json ke Google Drive / WA ke nomor sendiri.
  • ✅Selalu buka dari ikon yang sama. Beda browser = beda data.
  • ❌Jangan hapus "Riwayat & data situs" browser, dan jangan pakai mode Penyamaran.
  • 🔁Ganti HP: Backup di HP lama → Restore Data di HP baru.

🚀 Setelah terbuka

  • 1️⃣Ketuk Isi Data Contoh untuk melihat simulasi.
  • 2️⃣Atur potongan Shopee/TikTok Shop di Pengaturan.
  • 3️⃣Tambah produk, lalu catat jualan dengan tombol +.
  • ❓Bingung? Buka menu Bantuan di dalam aplikasi.
