Cara Pasang KasRapi
di HP & Laptop

Ikuti kolom sesuai perangkat Anda. Selesai dalam ±3 menit, lalu ikon KasRapi siap dibuka setiap hari seperti aplikasi biasa.

Unduh & ekstrak file dari Lynk.id

Buka link unduhan di email/halaman pesanan Lynk.id → ketuk Unduh. Jika berupa file .zip, ketuk file tersebut lalu pilih Ekstrak. Yang Anda cari adalah file Aplikasi-UMKM.html.

AndroidSamsung, Xiaomi, Oppo…
  1. 1Buka File Saya / Pengelola File / Files by Google → folder Download.
  2. 2Tekan lama file Aplikasi-UMKM.html → Buka dengan → pilih Chrome → Selalu.
  3. 3Saat KasRapi terbuka, ketuk ⋮ (kanan atas) → Tambahkan ke Layar utama → Tambahkan.
  4. 4Ikon KasRapi muncul di layar HP. Buka selalu dari ikon ini.
Menu "Tambahkan ke Layar utama" tidak ada? Ketuk ☆ untuk Bookmark, lalu buka dari menu Bookmark Chrome.
iPhone / iPadButuh 1 aplikasi gratis
  1. 1Unduh lewat Safari → file masuk ke aplikasi File → Unduhan.
  2. 2Pasang Documents by Readdle dari App Store (gratis, sekali saja).
  3. 3Di aplikasi File, tekan lama Aplikasi-UMKM.html → Bagikan → pilih Documents.
  4. 4Buka Documents → ketuk file. Tandai Favorit & taruh ikon Documents di Dock.
iPhone tidak bisa menjalankan file .html dari aplikasi File bawaan (hanya tampil teks). Karena itu pakai Documents, tetap offline.
Laptop / PCWindows & Mac
  1. 1Pindahkan Aplikasi-UMKM.html dari Downloads ke folder tetap, misalnya Dokumen.
  2. 2Klik dua kali file. KasRapi terbuka di Chrome, Edge, atau Safari.
  3. 3Tekan Ctrl + D (Windows) atau ⌘ + D (Mac) untuk menyimpan sebagai Bookmark.
  4. 4Opsional: klik kanan file → Kirim ke → Desktop (buat pintasan) (Windows) atau Buat Alias (Mac).
Tampilan laptop otomatis memakai menu samping (sidebar) dan grafik lebih lebar.

🛡️ Agar data tidak hilang

  • ✅Backup tiap minggu: Pengaturan → Backup Data → simpan file .json ke Google Drive / WA ke nomor sendiri.
  • ✅Selalu buka dari ikon/aplikasi yang sama. Beda browser = beda data.
  • ❌Jangan hapus "Riwayat & data situs" browser, dan jangan pakai mode Penyamaran.
  • 🔁Ganti HP: Backup di HP lama → Restore Data di HP baru.

🚀 Setelah terbuka

  • 1️⃣Ketuk Isi Data Contoh untuk melihat simulasi.
  • 2️⃣Atur potongan Shopee/TikTok Shop di Pengaturan.
  • 3️⃣Tambah produk, lalu catat jualan dengan tombol +.
  • ❓Bingung? Buka menu Bantuan di dalam aplikasi.
