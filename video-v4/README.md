# KasRapi V4 — Fitur Aplikasi (TikTok 9:16)

Video promosi 39 detik yang memamerkan fitur asli KasRapi (data contoh bawaan "Dapur Bu Rina").
Gaya: neo-brutalis warna cerah (halaman warna per fitur, kotak hitam tebal, bayangan keras, screenshot app sebagai stiker).

- `src/shot2.js` — ambil screenshot aplikasi dengan Playwright
- `src/proc.py` — rapikan voiceover Speko (voice Puck) per scene
- `src/tl.py`, `src/render.py` — timeline + render frame PIL → ffmpeg
- `src/audio.py` — mix voiceover, SFX numpy, dan musik ketukan
- `output/KasRapi-V4-FiturAplikasi.mp4` — hasil akhir
